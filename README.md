# 🏭 Dashboard de Produção | Power BI

Dashboard interativo para acompanhar a operação de produção: **quantidade produzida**, **quantidade rejeitada**, **horas produtivas e paradas**, com indicadores de **qualidade** e **produtividade** e filtros por operador e período.

## ✨ Recursos

- Indicadores de **Qtd Produzida**, **Qtd Rejeitada**, **Horas Produtivas** e **Horas Paradas**
- Medidores de **% Qualidade** e **% Produtividade**
- Evolução da produção ao longo do tempo
- Filtros por operador e por data de início

## 🛠️ Tecnologias

Power BI Desktop · DAX · Power Query

## 🚀 Como abrir

Baixe o arquivo `.pbix` e abra no **Power BI Desktop**.
